## Requirements

- Python 3
- Visual Studio Code or another Python editor

## How to Run a Program

1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open the Python file you want to run.
4. Run the file using the Run button or the terminal.
5. Enter the requested input values and check the output.

Example terminal command:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python program you want to run.
